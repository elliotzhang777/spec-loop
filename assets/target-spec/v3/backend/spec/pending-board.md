## 使用规则

- 后端 `TASK` 和前端 `WEB-TASK` 创建后均加入此表。
- 开工后把状态更新为 `进行中`。
- 实现完成且需要验证时，从此表移除并加入验证看板。
- 无需独立验证且已满足完成定义时，写回正式规格后直接移除。
