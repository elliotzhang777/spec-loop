## 使用规则

- 只有实现已完成并具备验证条件的工单才能进入此表。
- 验证失败：把结论写回工单，工单改为 `进行中`，移回待完成任务看板。
- 验证通过：把证据写回工单，工单改为 `已完成`，同步上游规格，再删除本表条目。
- 本表为空表示当前没有等待验证的交付，不表示没有交付历史。
