## 验证范围

- 层级：默认使用 Task 增量验证；只有整轮最终验收工单使用 Wave 全量验证。
- 所属波次：待填写，例如 W1。
- Task Gate：只覆盖本工单 AC、改动模块和直接依赖，不重跑已交付兄弟工单的完整 Gate。
- Wave Gate：所有工单合入后，由独立 Heavy 工单统一运行一次跨模块、端到端和对抗验证。
- Gate 配置：普通工单使用 `coverage: targeted`；只有最终 Heavy 工单使用 `coverage: full`。
- 数据库：默认复用长期验证实例并使用事务/Fixture/schema reset；只有迁移或初始化类 Heavy 验证可以声明一次性数据库及原因。
